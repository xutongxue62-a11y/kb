# v0.13 — 三角色外观与单份掉落

在 2026-11-15 接力交接后的最新磁盘版本上原地继续。旧素材、玩家进度及职业/蛋/武器布局更新均保留，未恢复旧版快照。

- 原始人：橙色乱发、无胡须笑脸、单肩黄皮衣；酋长：银白发须、三羽冠、青绿披肩；野蛮人：黑色硬发、怒眉獠牙、深毛皮与暗红腰裙。角色 ID、能力、初始武器与选人逻辑保持原样。
- 三套 body 由内置 imagegen 生成，原文件及精确提示词在 `assets/characters/v13/`。立绘通过 `tools/export_character_portraits_v13.gd` 直接渲染同一个战斗 ActorView，manifest 记录其身体/立绘指纹。正常尺寸轮廓、描边透明边距、四边留白均有回归检查。
- 每份基础经验、每枚金币各生成一个 `value=1` 的独立地面物，确定性散开不占用战斗 RNG；原来的怪物/精英/Boss/石头随机奖励规则不变。地面去掉 ×N，伤害飘字和 HUD 总数保留。
- 旧 `value>1` 存档在恢复时等量拆成单位物。已经拆分的物体再次读档保留原位置；旧格式曾允许的分数经验以最后一份物体上的小数权益保留，拾取时按原经验倍率入账，保存/继续不会重复拆分或提前入账。
- 删除 240 个后的自动入账。更新原地压缩、平方距离判定；缓存两类手绘图标，按纹理提交并裁剪屏幕外的绘制。所有未拾取物仍是独立实体。存档校验从旧 256 个提高到 50000 个，保留 8MiB 文件与异常大旧包的安全验证；超出校验会明确保存失败，不吞掉落。

完整回归使用 `tools/run_tests.ps1`，本次增加 `character_loot` 组。新成绩、原生录制、5000 实体同屏测量、指纹和玩家存档保护结果见 `character_loot_v13_verification.json`。测试与录制全部使用 `runtime/tests` 下的独立 SaveStore。

最终原生预览：`previews/character_loot_v13_v4.mp4`；逐张选人/战斗/八份掉落/部分拾取继续/全部拾取图在同名目录。早先 v1-v3 的录制调试证据保留，不作为最终通过证据。修复了原生立绘导出右手被边界裁切的问题；独立只读复核未留 P1/P2。

技术验证与原生截图不替代用户视觉/手感验收；未宣称主观试听。启动仍可使用工程根目录原来的 `启动样板.cmd`，窗口标题为 v0.13。应用名和真实存档目录没有改变。
