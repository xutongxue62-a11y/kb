# UI v31：确认后的奖励、商店与换装排版

用户已确认 v30/v31 原生预览，并明确要求应用到正式游戏。本版已合入正式 `src`，启动入口仍为项目根目录的 `启动样板.cmd`。

## 本次改动

- 武器、属性和支援类奖励均可单独出售换取金币。BUFF 按当前层数对应的购买价五折向下取整，至少 1 金币；武器继续使用原有出售价格。出售只消耗当前选中的一份奖励，保留已有装备、BUFF 层数及其效果。经验升级和排队宝箱沿用原结算流程。
- 奖励与商店使用清楚的等级或“层数 2 → 3”提示。属性直接显示具体数值，例如“暴击率 +6%”；层数上限读取实际配置，不将全部属性统一改成 15 层。
- 商店操作明确写出“购买新武器”“购买升级”“购买并更换”“购买并强化”及实际金币价格，治疗、售罄和金币不足也分别说明。类型居中，说明、层数上限及交易行提高可读性。
- 更换页六张卡片完整放入卷轴；去掉类别框，等级、攻击类型、具体攻击方式、进阶/觉醒能力和出售所得分行显示。顶部新武器图标与名称紧邻组成居中组合，补充完整攻击方式及两阶段能力。
- 保留已确认的纸张颜色、图腾花纹和刷色交互；仅调整侧边图标卡片的花纹避让。原图标、背景和卷轴动画沿用现有素材与实现。
