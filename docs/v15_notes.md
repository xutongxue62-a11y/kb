# v0.15 — 武器收近与材质细化

从 v0.14 的已核验磁盘版本继续，保护快照见 `v15_baseline.json`。旧素材、旧预览和玩家进度保留。

此前武器挂点已经靠近手部，展示时又额外向外平移了约 0.82 倍武器长度，导致骨弩等武器明显悬远。这次改为各武器自己的握持长度：单持骨弩的闲置纹理中心到角色中心由约 84.3 像素收至 56.9 像素。其他远程、法器、投掷物和辅助武器也整体收近，六武器的上下排错开，避免中下排相互遮住。

环绕近战的展开半径由 118 调至 100 像素，收束由 88 调至 74 像素；命中仍按实际武器位置计算。远程的射程、弹道与目标选择保留。骨弩闲置时向外展示，瞄准、发射和后坐时保持真实箭向；骨矛突刺、回旋骨镖飞行仍使用各自的动作。

美术沿用现有手绘轮廓，原生 SVG 增加骨质、木质、石材和晶体的轻微明暗渐变，进阶镶嵌增加小块高光。攻击瞬间的武器放大从最高 24% 降至 10%，避免收近后盖住较宽的角色身体。未覆盖既有 PNG；三位角色、UI、音乐、技能等级、可选联动、关末吸收与结算沿用 v0.14。

实际预览：`previews/v15_native_v4.mp4`；距离对照：`previews/v15_native_v4/layout_before_after.png`；14 件武器的 1/3/5 级纹理：`previews/v15_native_v4/weapon_growth_sheet.png`。距离对照两列使用同一套新素材，仅比较旧/新挂点与握持位置。

验证由 `tools/verify_v15.py` 汇总到 `v15_verification.json`。回归覆盖所有武器、两个阵型、三个外形阶段、三位角色的实际不透明像素遮挡，以及骨弩在闲置展示锥外的真实射击朝向。测试与录制使用隔离 SaveStore，最新真实进度另行逐文件备份，不回写旧存档。技术和原生画面核验不代替用户手感验收，未宣称主观试听。

本轮结果：37 组 / 6601 项回归、13 项原生录制检查通过，最终录制的引擎与控制台日志均无错误或警告。156 个旧素材文件、72 个其他源码文件保持一致；4 个真实进度 JSON 已备份，测试期间未变化。v0.15 正常游戏窗口已打开，启动凭据见 `v15_opened.json`。
