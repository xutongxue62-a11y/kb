# 原始人大作战 v0.2：近身武器与有代价的二联动
日期：2026-11-14。用户最新修正覆盖 v0.1 的全部三件组合和远程绕圈方案。

- 当前角色与画风保持，身体和四肢独立协调运动，最多六武器、正常一把开局、同名升级。
- 远程固定在角色身边，只瞄准目标；近战半径从112/76缩短至76/60 px。
- 只允许两两联动，可选择不联动，取消三件联动和无关的命中计数范围圈。
- 每把武器最多参加一个联动，配方不消耗原武器与等级；当前配方共享火药筒，因此一次只能选一种或关闭。
- 火药筒+魔法杖：符火炮弹带魔法核心、火焰尾迹及短范围灼烧；代价为法杖停止独立发射、火药筒装填间隔增加到1.5倍。
- 火药筒+近战：该近战武器由链条弹射出去再收回；失去持续环绕护身，火药筒不再发普通炮弹，射程210 px而非395 px。
- 即使同时持有火药筒、近战、法杖，也不能叠成三件联动；未参与配方的武器独立攻击。
- Q/按钮在可用配方与“不联动”之间选择。关掉锁链时先收回武器，不消失或瞬移。
- 加入原创短音效：挥击、命中、爆炸、锁链、施法、脚步。限声部、限幅；声音与特效服从战斗可读性。
- 录制带声音的引擎演示，清楚比较不联动、符火、锁链。非静音/峰值检查不能替代主观试听。
- 旧代码、旧测试、旧图和旧录像均保留。
