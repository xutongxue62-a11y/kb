# v0.12 荒野交锋接入记录

2026-11-15。保持已认可的v0.11 UI布局、按钮、卷轴、转场和四首场景音乐，12个UI脚本逐字节一致。开始修改前349文件快照见v12_baseline.json；本轮没有替换旧贴图/音频。

## 战斗、石头与掉落

- 主角新增固定在静止双脚下的五层柔和阴影，人物起伏/走路时投影仍贴地，不加脚底色圈。
- 岩石生命为14+8×缩放，实际玩家武器/支援可命中，破损出现裂纹，打碎变成小碎石并立即解除身体碰撞。稳定ID包含地貌/区块坐标/石头序号，HP独立保存，区块回收/存读不重刷或重复发资源。
- 自动攻击优先射程内的活敌，无敌人时才瞄准石头；穿刺和范围攻击可以顺带采石。每块石头只发一次1–2金币、1–2经验，不记成怪物击杀。
- 怪物的金币/经验使用LootRules区间随机。第1关猎手金币1–2/经验1–2、冲锋兽2–4/2–3、吐毒兽2–3/2–3、坦克3–6/3–5；新迅龙2–4/2–3、投掷兽3–5/2–4、岩甲兽5–8/4–6，Boss18–26/10–16。
- 随关卡增加有限的资源档位，体型带来额外奖励，精英再翻倍。不会因玩家无限堆Buff而无限放大掉落。图标约放大一倍：金色硬币与绿色切面晶体有暗描边、高光和小投影；大于等于5的资源包显示数量。
- 弹弓皮筋回弹与有描边的石弹、炮口闪焰/火尾重弹、法杖符文与三枚青色符弹分别绘制。雷鸣图腾改为带亮芯/暗轮廓的折线及分叉电弧。去掉遮住这几把远程武器的旧圆形aura，保留枪口、亮化与命中。弹道碰撞半径和原联动代价保持。

## 四武器与三怪物

武器池从10增至14，仍最多六槽、同名五级；新增项进入真实加权成长、商店和存档。

| 新武器 | 机制 |
| --- | --- |
| 骨弩 bonebow | 实际飞行骨箭，最多穿过3个目标，每箭不重复命中同一目标；按武器挂点选择可达射程。 |
| 火种壶 firepot | 抛掷落地，延迟引燃后持续范围灼烧，最多6跳。 |
| 战鼓 wardrum | 三拍扩散震环，逐拍命中，每个环不会反复刷同一目标。 |
| 晶簇 crystal | 放置并武装，敌人靠近后触发六向晶片，同一簇共享命中记录。 |

等级、攻速、范围和相关弹速属性实际生效。新弹丸、火场、震环、晶簇都有有限寿命；卸装/换关清理。F3在原四扩充武器和本轮四扩充武器两组试用间切换，F2仍为原基础六武器。

普通怪从4种增至7种，加原Boss共8种。新增独立代码SVG美术，粗描边/平涂手绘，三种轮廓及行为均不同，保留64源像素透明边距与精英贴体红边。

- 镰爪迅龙：侧移接近，0.58秒锁定预警后扑击。
- 投掷兽：保持距离，0.78秒扇形预警后投出三枚实际石弹，与紫色毒弹区分。
- 岩甲兽：低速重型，1秒预警后震地，危险范围与实际112半径匹配。

正常第2关加入迅龙、第3关加入投掷兽、第4关加入岩甲兽；试用可直接遇到全部。攻击预警、定时、速度、击退和地形碰撞沿用统一主流程，不用帧数冒充实际时间。

## 关卡衔接与保存

- 普通关30秒/击败Boss后，清除所有活敌和飞行威胁，播放消散退场，不给未击杀怪物假奖励。角色与武器保持当前姿态，冻结0.9秒，只有退场特效继续；随后才打开现有商店。
- 商店离开仍先收卷；下一关的敌人、弹丸、地面攻击与旧特效清空，开头至少0.55秒空场，之后从镜头外进入或有蛋壳孵化预警。Boss也延迟从右侧场外进入，不能突然生成在角色附近。
- 结算冻结的战斗钟、移动、武器、熔岩和攻击不推进；最后一帧真实致死仍先于过关。结算状态可保存恢复，保证进入正确商店。读取旧版本缺少新字段的存档仍有效；敌人的瞬态攻击沿用原先安全恢复方式，不作逐帧回放。
- 独立复核找到并修复两项P2：进入试用前先保存原正常局再重置碎石状态；关末锁链飞行中排队切换配方，下一关归位时结清，避免武器停火。另补骨弩左侧挂点边缘范围回归。
- 测试和录像使用runtime/tests。开发期间旧版正常试玩持续产生了更新的玩家进度，因此最终保留最新存档并另作逐字节备份，未用开始时的旧快照回滚。最终备份路径、哈希和兼容检查见v12_verification.json。
