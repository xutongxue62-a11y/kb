# v0.10 行旅战场接入记录

2026-11-15。包含用户追加的“地图比视口大、向外探索、内部布景和熔岩坑”要求。

## 世界与地图

- Main新增Camera2D，角色、敌人、武器、拾取物和特效都使用真实世界坐标，HUD仍为CanvasLayer。行走和闪避不再被原FIELD矩形截断。
- world_map.gd按512px区块生成/回收，坐标决定稳定种子；回到同一区块，石头、落叶、草和坑的位置一致。远离区块可丢缓存，需要时重建，测试连续移动80次缓存不超过64块。
- 视野周围继续生成地形，未使用“整张一屏地图”的四边围草。三张生成图仅取中部无道具区域做镜像连续纸纹，岩石/落叶和熔岩坑独立放在世界内部。
- 关卡1–4荒草原，5–8蕨叶林地，9起熔岩荒原；熔岩坑有起伏气泡、亮边和破泡小滴。目前是环境动画，不额外改变战斗伤害。
- 敌人从当前世界视野附近进入/孵化，远处敌人回收时保留身份、残血和精英状态，不产生假击杀/奖励。存档保留真实负/大坐标、地面宝箱，旧版本坐标也可读。

## 角色、武器与HUD

- 恐龙原图完整，根因是裁片只有约2px透明余量，而描边实际需要约8–18px，另有低透明背景噪声。现在四种怪物使用独立留边纹理，透明余量64–65源像素，Boss复用坦克；清除alpha≤8/255的无意义噪声，保留本体、原屏幕大小和原PNG。
- 精英仍为贴合身体的红描边，无装饰红圆圈；蛋沿蛋壳轮廓描边。首页怪物和死亡残影也按原本体尺寸缩放，避免新增透明留边导致缩小。
- Shift闪避：0.20秒、140px、1.4秒冷却，方向锁定和短暂无敌，保留已有更长保护；暂停/成长/商店/出发等阻挡状态不消耗。读档和重开清理瞬态闪避。
- 原有联动未删除：需获得火药筒+法杖或火药筒+近战武器，再按Q切换；保留装填/射程/停射代价。加强符火注能、炮口符文、弹道和灼烧、金色出链/青色回链，以及矛/槌/骨镖/近战差异反馈，伤害未改变。
- 新HUD把生命/经验放到左上残纸卡片，数值和关卡分开，控件圆角，武器栏及闪避冷却在底部。Q状态与配方说明更醒目；火山上底部说明也有纸底保证对比。
- 首页保持已认可布局，增加武器攻击节拍、短弹道、主角反冲和不同怪物动作。

## 背景音乐

新增本地原创《篝火行旅》26.667秒循环：8小节、72BPM、五声悬和声、木质拨弦/气息旋律/轻手鼓。无下载采样。素材与脚本：assets/music/v10/campfire_trail.wav、tools/make_game_music_v10.py。

MusicController只有一个懒加载声部，0.35秒淡入/淡出；设置关闭后实际停止播放，重新开启继续工作。保存music_enabled，兼容旧设置，自动保存开关独立。载入保存开关后再加入场景，避免静音用户开机先响。

原音轨峰值-3.35dBFS、RMS-17.66；场景播放增益title -10、battle -12、volcano -11、pause -18dB。无削波，DC约1.13e-8，循环边界步进0.001038。实际首页增益试听为assets/music/v10/campfire_trail_title_gain_preview.wav。模型不支持音频输入，技术测量不能代替用户听音。
