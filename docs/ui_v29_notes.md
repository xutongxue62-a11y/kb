# UI v29 — 用户确认版合入

用户确认的画面：`previews/native_ui_v29/reward_cave_mid.png`。以这版为准合入正式工程，之前各版预览保持原样。

- 常态保留细纸纹与不规则壁画、小兽、人物、日纹笔触。左右形状与角度错落，坐标固定，不逐帧闪动。
- 左到右刷色盖住对应部分花纹；刷满或按下后为干净实色。首页、通用按钮、奖励/商店卡片、出售和设置开关复用同一遮罩规则。
- 武器卡使用暖黄橙色悬停，出售动作使用红色；原本的赭红主按钮刷成米白，按下仍有压纸与独立色块反馈。
- 奖励卷轴采用确认过的暖色厚纸卷外观，展卷、收卷和离场行为保留。奖励仍三选一，六项仅为兼容布局，不改变抽取规则。
- 奖励与商店分别标出武器名字、等级、攻击方式/伤害表现、等级能力。满槽更换和直接升级分别提示。奖励无分类方框与概率小字。
- 出售只转换所点的这一份奖励，保留已装备武器，不自动出售未选奖励。原有商店购买及替换售回规则保留。
- 设置开关的滑块与“开启/关闭”使用固定内容区，保留 CheckButton 状态、点击和信号行为。

只合入六个已有 UI 脚本与四个新增 UI 脚本。`main.gd`、`hud.gd`、经济/成长/存档/战斗逻辑和原素材保持当前盘内容。独立只读审查未发现 P1/P2；合入时仅把弹弓说明中的“单个目标”澄清为“沿飞行路径命中敌人”，避免与高等级回弹及贯穿加成产生歧义，未改变玩法。

安装前完整快照见 `native_ui_v29_baseline.json`。安装记录见 `ui_v29_install.json`，正式工程的全量回归、原生截图和花纹遮罩像素核验结果见 `ui_v29_verification.json`。测试使用隔离 APPDATA 和显式独立 SaveStore，不覆盖玩家进度。

本次为已确认 UI 的合入；地面拾取宝箱外观、角色切换的横向烧纸过渡仍按原交接待做。奖励卷轴不改为燃烧。
