# v0.8 动效、音效和武器可读性修订

用户实玩反馈：上一版动效几乎都为同一个左到右擦除，音效刺耳且重复；燃烧不够可见；选人箭头难看；武器与人物重叠。用户要求参考《翻面》整体动效重新设计并接入现有游戏。保留既有画风、角色、流程和存档。

参考动态证据：已保存的用户指定 BV1RYxv6oEtw 原视频，0.00–0.88秒逐帧可见背景保持、标题缩位、菜单及信息纸片分批出现，而非全页横向擦除。127.5秒附近展示菜单与军械库场景切换。参考仅用于节奏/层次和墨线反馈，保留本项目主角/武器/恐龙。

设计：选人页分层上浮/淡入；普通弹窗从中线纵向展开；成长与营地为具备卷轴端帽、螺旋和卷边的左右展开；返回轻翻页；确认出发为中心向四周扩散的可见烧蚀孔洞、焦黑纸沿、手绘火舌和灰烬，持续约0.9–1.0秒。所有图形纯2D。按钮反馈为墨线/边角标记与短促纸面下压，不再粗暴缩放/变扁。

选人前后按钮改为无底框手绘箭头，移到角色下方的计数左右；只有一角色时保持可见置灰。选人弹弓与手留出空隙。战斗远程挂点外移约20像素，保持固定近身/瞄准/发射一致，不改伤害和冷却；近战已有足够空间，维持判定半径。

UI声音全新另存ui_v08，悬停静音，页面/弹窗/卷轴/燃烧/确认分别用轻柔纸张与短触感声音，避免旧电子感及大音量、避免多层重复播放。不得用声波检查宣称已听过；本环境不能接收音频输入，导出含标注的试听与原生演示供用户验收。
