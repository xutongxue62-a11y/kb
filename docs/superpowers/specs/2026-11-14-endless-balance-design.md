# 无限关卡与怪物成长（最新试玩补充）

用户明确要求无限关卡，30秒或1分钟一关；怪物血量、伤害、闪避要成长，每3或5关显著加强，并参考当前配装，避免后期玩家数值失控。承接正在完成的开局/近战/辨识与特效修改。

- 采用30秒一关，无固定90秒胜利；死亡后结束本局。每关边界给一次免费成长并保留经验。
- 每5关一次明显加强，每3关逐步提高精英比例。普通敌人、冲锋、远程和重甲具有不同基础伤害与闪避。
- 血量按每关约10%与每5关额外45%成长；伤害使用较缓的线性增长与每5关额外18%。移速逐渐增加但最多+35%，敌方弹速最多+30%。
- 每5关读取当前武器、等级、伤害/攻速/暴击 Buff、支援和联动代价的估计输出。相对该阶段预期输出做温和修正，额外血量倍率最高1.65，不在每次升级后即时抵消玩家成长。
- 加强现存敌人时保留其剩余生命比例，不瞬间回满。新敌人使用同一当前关卡基准。
- 前两关无敌方闪避；后续普通敌人缓慢增加、最多22%，精英最多30%，重甲的闪避更低。鹰眼每级抵消4个百分点闪避；爆炸与地面灼烧不可被随机闪避。
- 敌人闪避显示“敌闪避”，玩家闪避保持青色；实际伤害、暴击使用更大字号、更深描边，并延后淡出。
- 高关卡内部数值采用有限安全范围，避免浮点溢出；关卡计数继续推进。
- 保留全部现有武器槽、Buff等级上限、可选有代价的两两联动、已有原图与历史版本。

验证覆盖无限跨90秒、第五关加强、配装估值与倍率上限、生命比例保持、敌人实际闪避及命中抵消、AoE不被闪避、敌方实际伤害，以及高关卡有限值。原生画面与主观爽感仍需分开说明。
