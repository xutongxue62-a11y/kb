# 可分发版本与内容更新接入

用户要求把已批准的 UI v31 游戏做成别人下载即可玩的发行程序。最终范围明确为 Windows、Linux、Android，不打包 macOS。用户已选择“暂时没有服务器，先做好包和更新接入”。

采用现有 Godot 4.7.2 官方导出，不升级引擎。由构建工具复制最小项目到独立准备目录，排除真实存档、开发日志、测试、历史预览和工具。桌面导出独立运行时与 PCK，分平台压缩；Linux 归档保留执行权限。Android 使用正式密钥签名 APK，包含 ARM64 与 ARMv7，横屏并补充触屏移动与双指闪避。SDK/JDK 使用项目私有便携目录，不改系统环境。

选择现有引擎导出而非捆绑编辑器：体积较小，玩家无需安装 Godot。选择启动前加载内容包而非运行中替换脚本：保留现有资源预加载行为，更新在下次启动生效；引擎、启动器自身更新另发完整包。网页随部署版本刷新，不承诺桌面式文件更新。

发布专用入口 `release/bootstrap.tscn` 在独立构建副本启用，开发入口保持 `main.tscn`。入口不预加载游戏源码，先校验并挂载已下载内容，再动态加载游戏。后台更新默认无地址、立即离线进入游戏；后续配置 HTTPS feed 后检查签名清单、平台、构建号、引擎和启动器兼容性，再下载到临时文件，校验字节数与 SHA-256 后原子登记。无效、过旧或未完整的包不激活。RSA 私钥和 Android 签名密钥仅保留在独立准备目录，不进入工程资源或发行包。

补上开放许可中文字体作为系统字体的后备，保留 Windows 当前优先字体及粗细。保持已批准美术、已有玩法和存档格式；原 156 项素材与 4 项玩家存档不得被改写。

验收分开记录：文件已导出、Windows 原生实际运行、Linux/macOS 导出但尚未在真机运行、网页浏览器实际运行、手机触控模拟与真机验收。不能把“导出成功”写成“所有设备实测通过”。
