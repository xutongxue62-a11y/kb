# v0.11 交互、成长与战斗反馈

用户授权继续接入游戏，保留已有地图延展、镜头、闪避、联动与原图。修改点：怪物接地阴影；手绘异色悬停，彻底移除底横线/上方角框/胶囊圆按钮；成长卷轴不遮挡并完整收卷退出；武器摆位/攻击语汇更清楚；显著加强可叠层的后期攻速/暴击成长，叠得越高抽取权重越低并显示概率；支援幼龙/飞行器重画并增强；最后10秒/5秒醒目红色倒计时；商店六种随机商品；石头实际阻挡，熔岩对玩家与怪物均产生中立伤害；首页、草原、林地、火山使用不同曲目。

选择：沿用真实控件与CanvasLayer布局，纸片以斜切/残边绘制、悬停显著换色而非额外挂框。卷轴用独立前景卷筒、裁切与输入锁，收卷期间战斗保持停止，动画结束后消费已选结果并恢复（无双选）。概率标明计算含义，使用真实候选池权重，不能把权重误写成三选一整轮出现率。

成长上限与保存校验同步，旧三层档有效；基础0Buff武器输出不随意改写。后期强化由更高层数/明显增益产生，保持攻速计算、碰撞与支援实际生效。商店正常候选足够时恰好六种互异商品，不凭空放入不可拥有的第七把新武器。

岩石碰撞使用与画面一致的世界坐标道具，支持负坐标/区块和移动/滑移/闪避，无穿透；熔岩以固定时间伤害结算，暂停/成长/商店不推进，中立伤害不吃玩家增伤，不重复死亡/掉箱。怪物阴影为柔和接地投影，不重新添加精英脚底光圈。

音乐必须是不同编曲/音轨，不是同曲调音量；切换平滑、声部有界、关闭持久生效。支援新美术与原游戏手绘风匹配，原资产和存档保留。技术音频检查不能代替听音，最终以原生输入与动态录制验收。
