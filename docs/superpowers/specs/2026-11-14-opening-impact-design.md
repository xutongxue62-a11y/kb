# v0.4 开局力度、近战价值和阵营识别

用户试玩要求：开局更猛、近战应以伤害补偿风险、敌我混战时更容易分辨、特效更丰富。用户授权助手适当调整后再次试玩。

## 调整决定
- 仍为六武器、正常单武器开局、可选两两联动并付出原有代价；保持原始人/恐龙和全部旧图片。
- 木棒 8.5 伤害、石斧 12、骨刃 6；分别使用 10/8.2/14 弧度每秒的环绕挥击速度。通过真实碰撞与弹丸测试比较输出，不能只比较面板冷却。
- 弹弓 3.2 伤害 / 0.42 秒；法杖每弹 2 / 0.78 秒；火药筒 5 / 1.15 秒。保持远程便利，近战在可触及同一目标时输出明显更高。
- 开局四只普通敌人从 140–260 像素处进入；前 12 秒只有普通猎手，随后加入冲锋者，后两波保留远程/重甲威胁。普通猎手生命仍为 5。
- 首次成长需 3 经验，后续门槛缓升；基础拾取半径 100，探险每级仍加 50 和 15% 收益，减少开局拾取空档。
- 主角和伙伴用青色轮廓/标记；敌人用深红轮廓、红色脚下标记和红血条。主角顶部箭头在混战时持续可见。
- 近战拖尾为有厚度的弧面，命中有方向性冲击、受击闪白与更强击退；击杀有碎片与短暂消散，暴击数字弹出。爆炸有明亮内核、真实半径边界、烟团和冲击碎片；法杖增加符文与余辉。
- 仅使用轻微且限幅的受击震动，不通过长时间停帧中断移动；特效总量仍限制在 200。
