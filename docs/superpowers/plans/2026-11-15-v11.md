# v0.11 Implementation Plan

> **For agentic workers:** executing-plans handles root UI/VFX/integration; dispatching-parallel-agents handles independent terrain, growth/economy, and music/support domains.

**Goal:** 完成用户本轮UI、成长、支援、音乐和真实地形反馈。
**Architecture:** Main/WorldMap负责碰撞/中立伤害；Growth/Economy负责真实权重与六商品；Companions/MusicController各自独立；root重做通用按钮/卷轴/商店排版、概率展示、倒计时和武器语汇。
**Tech Stack:** Godot4.7.2、GDScript、内置image_gen支援素材、本地原创音乐、原生MovieMaker/PyAV。
**Spec:** ../specs/2026-11-15-v11-design.md

### Task1 真实地形和阴影（terrain agent）
- [x] dino_view脚底柔和投影；WorldMap.move_body(from,to,radius)滑移与小步防穿透；Main接玩家/怪物/闪避。
- [x] 世界内部熔岩固定中立伤害、状态门控、实际死亡/掉落一次；头less先RED再GREEN，输出可供支援使用的地形接口。

### Task2 成长和商店（growth agent）
- [x] Growth加强可叠Buff和递减抽取权重，提供真实概率/显示文本接口；SaveStore和旧测试同步。
- [x] Economy六个随机互异合法商品，最大配装/满血/耗尽候选也有明确行为；不改HUD。

### Task3 分场景音乐与支援（music/support agent）
- [x] 四首不同原创循环，首页/草原/林地/火山，暂停压低当前曲，关开持久；有界交叉淡化。
- [x] Companions更有用的追击/攻击，幼龙/飞行器新透明手绘图与动作，独立SupportArt.texture(key)用于UI图标；不碰Main/Growth/HUD。

### Task4 UI、武器与整合（root）
- [x] 所有按钮去旧方角/下划线，手绘换色与残纸小动效，不用胶囊圆角。
- [x] Buff卷轴边缘/顶部裁切修复、前景卷筒、真实收卷退出和输入/战斗锁。
- [x] 三选卡显示概率含义，商店3×2六卡与禁用/售罄状态；倒计时10秒/5秒分级红色提醒。
- [x] 武器姿态稳定、攻击轨迹/命中语汇分型，后期高攻速仍可读；接新支援、地形、音乐场景。
- [x] 完整回归、原生连续录制/多图/音轨、独立只读审查、哈希保留和文档；正常打开v0.11供用户试玩。
