# v0.22 — 按钮刷色与破损羊皮纸

本轮从用户继续修改后的当前磁盘版本开始，快照见 `ui_v22_baseline.json`。当前成长、武器替换/售回、存档和掉落等改动保留；没有回退到历史 v0.16。

首页“进入营地”“继续存档”“玩法说明”和其他纸面按钮加入悬停提示音：复用现有短按钮音，轻微提高音调并降低音量。只在指针进入有效按钮时触发，停留不重复；禁用、隐藏和页面忙碌时不触发。90ms 防抖，且为点击/翻页保留声音通道。

颜色由整块同步变色改为约 0.18 秒从左到右刷满。纸纹持续可见，前沿有羽化和不规则刷痕；移开时快速退回。阴影、纸面和墨线分层，字体在颜色到达文字位置时切换，避免浅纸上白字闪烁。现有按钮布局、点击路径、翻页音与卷轴开合流程保留。

羊皮纸与纸片按钮增加稳定的缺口、较深的局部撕口和细纤维，卷筒外皮也有轻微不规则边。轮廓不逐帧随机抖动；正文安全边距、裁切和卷轴两端保留。全部原始素材文件保持不变。

测试与录制使用独立 SaveStore。原生预览 `previews/ui_v22_final3.mp4`，同目录有刷色早/中/结束帧、成长纸卷和玩法纸页。`ui_v22_verification.json` 记录完整回归、真实渲染像素的左右刷色判定、录制音频与悬停短音的比对、当前源码范围与最新玩家进度备份。音频技术比对不代替主观试听，画面核验不代替用户验收。
