# v0.11 接入记录

2026-11-15。基于当前 v0.10 继续修改，原有区块世界、镜头、闪避、宝箱拾取、存读档和两类联动保留。修改前259文件快照见 v11_baseline.json。

## 界面与战斗表现

- 首页按钮悬停从赭红渐变为青绿；其他纸片按钮使用异色墨染、轻压和残边，不再追加底横线/角框，也不使用胶囊圆角按钮。角色前后选择保留无框箭头。
- 成长与商店卷筒改为独立前景，内容留出安全边距；卷轴期间隐藏战斗HUD，包含试用成长按钮。卡片图片使用受控尺寸，修复实际录制发现的原图最小尺寸撑大问题。
- 成长选择、商店返回/下一关，先用0.36秒收卷，再消费结果或切换。收卷期间仍冻结战斗，防双击/快捷键重复提交。原有出发烧纸、返回翻页和设置折开保留。
- 商店使用3×2六格；售罄、无钱、满血状态仍直接显示。普通关最后10秒放大红色倒计时，最后5秒脉动强调，Boss不限时不套用倒计时。
- 怪物、精英、蛋和Boss增加柔和接地投影，保留贴体红描边，未添加精英光圈。
- 斧/刃等近战朝外摆正，除弹弓外武器绘制放大12%，原有挂点、弹道原点和攻击距离保持同步。木棒钝击、石斧橙色劈砍、骨刃紫色双细切、火药爆炸和青色符能各自区分。
- 高速命中飘字在同点短时间内合并真实伤害总值，附近最多4条；金色加“!”表示暴击。真实伤害结算未合并。血条只纵向轻脉动，连续熔岩伤害不会将横向尺寸撑出纸框。

## 成长、随机与支援

- 蛮力/攻速各20层，每层+18%，满层4.6倍。暴击率15层，每层+6个百分点，基础5%后最高95%；暴伤15层，每层+35个百分点，最高6.75倍。旧三层档仍有效，防御类原上限保持。
- 候选权重1/(1+已有层数)^1.1，加权不放回；卡片显示当前候选池首抽率，商店保留生成当时首抽率。文案明确这不是三选/六选整轮出现率。升级会相对降低该项下次权重；其他候选的变化也会影响归一化概率。
- 正常候选足够时商店恰好六种互异合法商品；治疗参与随机。若全部成长已满、合法候选不足六种，显示剩余候选，不复制或出售不可持有的新武器。
- 幼龙和骨翼石灵使用新透明手绘图，卡片与战斗共用美术。幼龙可追击370范围内敌人，地面移动受石头阻挡；飞行器420范围点射、飞越地面。两者最高6层，攻速受成长影响，有0.14秒最小冷却。
- 实际事件回归中，图腾10秒出手由11次到48次；支援固定目标10秒基础伤害177，满级且4.6攻速时2470.7（未乘全局增伤/暴击）。这些是控制条件下数据，不代表正常关卡最终平衡已验收。

## 地形与音乐

- 石头绘制多边形与碰撞共用数据，角色、怪物、击退和Shift按小步移动/滑移，出生/读档也处理重叠。地图仍按512px区块持续延展，支持负坐标。
- 熔岩内缘多边形与伤害采样一致，玩家与怪物固定2HP/秒中立伤害，不吃玩家增伤、暴击、护甲或随机闪避。Shift等已有短暂无敌对玩家有效；暂停、成长、商店、准备和冻结期间不扣血。死亡与掉落只执行一次。
- 首页《Embers and Footprints》72BPM、草原《Hunters on the Trail》80BPM、林地《Leaves Above the River》54BPM、火山《Under the Ember Mountain》76BPM为四首独立原创24–26.67秒循环，有不同旋律/和声/节奏。原v0.10曲目保持。
- 场景切换0.35秒交叉淡化、最多两个播放器；暂停压低当前曲而不换歌，设置关闭立即停声并持久。返首页、暂停/属性、成长和宝箱入口都刷新音乐上下文。未完成主观听音验收，原生录像使用引擎实际混音。
- 新图提示词与素材记录：../assets/supports/v11/generation_prompts.json、asset_qc.json。原图不改，运行时去低透明雾边、裁切并补对称透明余量。新音乐脚本：../tools/make_scene_music_v11.py；曲目记录：../assets/music/v11/manifest.json。
