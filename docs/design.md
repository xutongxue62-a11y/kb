# 原始人大作战：六武器战斗样板

日期：2026-11-14。来源：本轮用户确认当前原始人和画风暂用，要求手脚协调运动、六武器、二/三组合，并允许木质火药筒和魔法杖等原始奇幻武器。

当前“六个武器”按同时最多六把落实，覆盖旧五槽；开局仍一把。六件为本轮设计方案：木棒、石斧、骨刃、投石索、木质火药筒、魔法杖。每件保留自己的等级与攻击，组合不生成第七件武器。

## 可操作交付

- Godot 4.7.2 / GDScript，1280×800 本机 Windows 样板，60 秒可重开战斗。
- 主角沿用已确认方向，身体和四个分离手脚使用独立精灵；双脚交替、手臂反相摆动，停步归位，命中或攻击短促回摆。
- 四种恐龙：追击、预警后直线冲锋、喷吐圆弹、低速耐久。
- WASD/方向键移动，空格展开/收束，Q 比较二联动/三联动，Esc 暂停，R 重开。
- 正常开局木棒；击杀经验后从三项武器选择中取得新武器或同名升级。六武器试用按钮/F2 为独立测试预设。
- 两个引擎内演示模式：手脚动作近景、六武器战斗。录像标明为演示，不替代手动游玩检查。

## 武器身份与首轮值

| id | 武器 | 攻击身份 |
| --- | --- | --- |
| club | 木棒 | 环绕重击、少量击退 |
| axe | 石斧 | 环绕高伤砍击，转速较慢 |
| blade | 骨刃 | 环绕快速切割 |
| sling | 投石索 | 自动发射单体石弹 |
| powder | 木质火药筒 | 自动发射火药弹，落点小范围爆炸 |
| staff | 魔法杖 | 自动发射符能弹，展开时较散、收束时较集中 |

数值是可调的样板起点，未通过平衡验收。近战展开半径 112 px、收束 76 px；每把远程武器独立筛选射程内目标，默认最近，可开启射程内精英优先。阵型不得绕过射程和目标优先级。

## 联动方案

二联动模式：木棒+石斧“裂地重击”；骨刃+投石索“猎手追击”；火药筒+魔法杖“符火爆破”。
三联动模式：木棒+石斧+骨刃“碎骨震波”；投石索+火药筒+魔法杖“巫火齐射”。未凑齐三件时，剩余武器可组成不重叠的二件组。

Q 是样板中比较两种组合方案的入口，不意味着最终必须增加这项战斗操作。每把武器在同一模式只参与一组；不叠加同组基础二联动和进阶三联动。联动伤害不能再次触发联动计数，避免无限接力。
