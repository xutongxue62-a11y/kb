# v0.8 纸墨动效与声音

2026-11-15。按用户 v0.7 试玩反馈重做，保留已认可的手绘素材、角色与游戏内容。

## 实际路由

| 入口 | 动效 | UI 声音 |
| --- | --- | --- |
| 首页进入选人 | 背景延续，纸面升起，内容分层出现 | paper_popup |
| 设置、继续、帮助 | 纸面由中央向上下折开 | paper_popup |
| 关闭弹窗 | 旧纸面短淡收 | paper_close |
| 返回首页 | 纸面绕左侧翻折 | page_turn |
| 确认新局出发 | 不规则中心孔向四周烧穿，焦边、火舌、纸灰；0.98秒 | parchment_burn |
| 继续战斗存档 | 轻翻页后进入准备期 | page_turn |
| 成长、营地商店 | 左至右真实裁切展开，两端有卷筒及螺旋端帽 | scroll_unroll |
| 成长、购买确认 | 卡片反馈，关闭成长时短淡收 | choice_confirm |
| 普通局部按钮 | 墨线悬停、1.8%轻压 | button_press；悬停静音 |

准备仍为约2.4秒的3/2/1，期间计时、移动、刷怪、攻击与伤害冻结。输入锁覆盖纸面展开和转场，阻止连点穿透。首屏不播放多余开页声音；导航动作不同时叠加点击音和开页音。

## 手绘实现

ui_transition.gd 使用72段二维不规则轮廓烧蚀旧画面，火舌在局部法线坐标构建，避免朝下时自交；ui_paper.gd 的 PaperClip 与展开区域一致，内容坐标不随裁切漂移。新 ui_button_fx.gd 以真实按钮子控件绘制反馈，不截获鼠标。

选人箭头与角色计数放在角色下方，用无底框墨线，单角色禁用；角色预览弹弓移至身体外。游戏中火药筒(70,12)、法杖(-70,3)、弹弓(32,-67)；近战距离及联动链条挂点保留。

## 音频

新增 assets/sfx/ui_v08/ 的7种独立纸木噪声手势，由 tools/make_ui_foley_v08.py 本地生成，无外部采样。旧音效文件保留，UI 调用转为 UIAudio。没有悬停蜂鸣或同一电子扫频；4声部上限、每种音色独立冷却，满池丢弃新请求，不掐断尾音。

单音实际播放峰值约-24.36至-18.15 dBFS，无削波、端点为零。实际增益试听文件为 assets/sfx/ui_v08/ui_v08_preview.wav，精确时序见同目录 README.txt 和 ui_v08_manifest.json。当前模型不支持音频输入，本轮未完成主观听音验收。
