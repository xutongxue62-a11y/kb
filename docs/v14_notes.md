# v0.14 — 武器进阶与关末吸收

在 v0.13 最新磁盘版本上继续，保护点见 `v14_baseline.json`。未覆盖旧版角色素材或玩家进度。

角色身体与四肢不再应用蓝色轮廓材质，保留原本的手绘墨线、接地影和玩家标记。选人立绘在 `assets/characters/v14/`，仍由实际战斗 ActorView 原生导出，旧 v13 文件保留。

全部 14 件武器在 3 级进阶、5 级觉醒；现有 1–5 级存档直接按等级恢复，无需重开。战斗、HUD 和升级/商店预览共用同一套阶段纹理。绑带、镶嵌、尖刃按各武器本体位置绘制，保持原来的手绘风格和挂点体系。

| 武器 | 3 级 | 5 级 |
|---|---|---|
| 木棒 | 每三次命中震荡周围 | 每两次命中，震荡更广 |
| 石斧 | 击败目标后溅斩 | 每三次命中也触发大范围劈斩 |
| 骨刃 | 每四次命中追击 | 每三次命中交叉范围斩 |
| 弹弓 | 双石齐射 | 回弹三发 |
| 火药筒 | 爆炸留下余烬 | 爆炸另射四枚碎石 |
| 法杖 | 四枚符弹 | 五枚符弹并追加穿透 |
| 骨矛 | 扇面贯刺 | 二次扇面连刺 |
| 石槌 | 追加外围震波 | 延迟二段重砸 |
| 回旋骨镖 | 连续两轮往返 | 连续三轮往返 |
| 雷鸣图腾 | 雷链四跳 | 每跳向另一目标分叉 |
| 骨弩 | 双箭 | 三箭，穿透上限增至五名 |
| 火种壶 | 双壶铺火 | 三壶与更久的燃烧 |
| 战鼓 | 四拍 | 五拍，尾拍扩圈 |
| 晶簇 | 八向碎晶 | 可再次引爆的八向碎晶 |

多发武器分摊单发伤害，避免把发数增加与原本每级增伤无条件相乘。具体平衡可继续试玩调整。

新增三个可选的双武器联动，用原来的 Q 切换配方：

- **鼓风燎原（火种壶＋战鼓）**：鼓波接触已有火场后，将它增强一次；火种壶装填慢 15%。
- **雷晶共鸣（晶簇＋雷鸣图腾）**：雷击为附近晶簇充能，引爆时增加碎片；图腾施法慢 15%。
- **导雷骨箭（骨弩＋雷鸣图腾）**：弩箭实际命中扣血后向邻敌导雷；图腾停止独立攻击，骨弩装填慢 18%。闪避、已经死亡的目标和石头不会白送导雷。

不自动强配，不加入无关武器收益；保持已有有效配方和“不联动”选项。

关末顺序为：剩余活怪/蛋直接清除，不触发伤害、击杀、掉落或宝箱回调 → 已有金币/经验/宝箱飞向角色 → 处理已经赚取的经验升级与宝箱选择 → 最后进入商店。单份掉落实体仍保留；吸收过程中、奖励选择中保存/继续不丢失、不重发。商店使用吸收完成后的金币、经验状态。

验证见 `v14_verification.json`；实际预览在 `previews/v14_native_v2.mp4`，14 件武器的实际纹理对照图在 `previews/v14_native_v2/weapon_growth_sheet.png`。测试使用独立 SaveStore。技术与原生画面验证不代替用户手感验收，未宣称主观试听。
