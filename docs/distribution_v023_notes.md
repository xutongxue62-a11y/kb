# v0.23.0 发行与后续内容更新

本次按用户最终范围制作 Windows x64、Linux x86_64、Android ARM64/ARMv7 三个可分发版本，不包含 macOS、Web 或 iOS。玩家不需要安装 Godot。

## 发给朋友的文件

发行目录为相邻的 `原始人大作战_发行版/v0.23.0`。只需要分享以下三个文件中对应平台的一份：

- `PrimitiveWildfrontier-v0.23.0-Windows-x64.zip`：完整解压，双击其中的 `PrimitiveWildfrontier.exe`；旁边的 PCK 文件要保留。
- `PrimitiveWildfrontier-v0.23.0-Linux-x86_64.tar.gz`：解压后运行 `启动游戏.sh` 或 `PrimitiveWildfrontier.x86_64`。归档内两个入口均保留 0755 权限。
- `PrimitiveWildfrontier-v0.23.0-Android.apk`：面向 Android 7.0 / API 24 及以上 ARM 设备，已用保留的正式发布密钥签名。安装后横屏游玩，左侧摇杆移动、右侧闪避，其他操作使用原有可点击按钮。

首次发行版默认离线，更新地址为空，不会因服务器未配置而卡住。包内包括开放许可中文字体后备，保留 Windows 原优先字体。原有配色、花纹、图标、奖励出售及卷轴交互沿用已确认版本。

## 验证边界

完整记录见 `docs/distribution_v023_verification.json`；该记录完成后方可将本次发行标记为已验收。Windows 使用实际导出程序检查原生首页/战斗画面，并通过真实 Godot 输入事件模拟多指移动、闪避及松手停止。Linux 的导出、ELF 架构和归档权限已检查，Android 的 APK 签名、资源、架构与最低系统版本已检查。当前没有 Linux 图形设备或已连接的安卓设备，因此后两者尚未完成真机试玩。

开发工程的真实存档没有随包分发，也未被测试覆盖。发行版使用各系统个人用户目录中的 `user://saves`。开发版原有进度仍在本工程 `runtime/Godot/app_userdata/原始人大作战 · 战斗样板/saves`；如果只迁移自己本机进度，应单独复制自己的存档，不要放进公共发行包。

## 更新何时生效

已经接入签名内容更新：下载完成后先核验清单签名、平台、构建号、引擎版本、启动器 API、文件长度和 SHA-256，再原子登记，下一次启动才加载。运行中不会替换已加载脚本。未完整下载、校验不符或不兼容的文件不会启用；启动不完整会保留失败标记，下一次改用上一份可用包或内置包。未就绪的游戏树会被移除，防止残留按钮改写正常存档。

目前没有真实更新服务，所以这份离线包不会自动发现后续版本。地址确定后：

- Windows / Linux 可在程序旁的 `updates.json` 填入真实 HTTPS 清单地址。
- Android 需要先用真实地址重打一个启用版并覆盖安装一次；之后同引擎、同启动器 API 的内容更新可以自行下载并在下次启动应用。不能让已经发出的空地址 APK 凭空知道未来服务器。
- 需要更换 Godot 引擎、启动器、原生权限或 Android 平台代码时，仍需完整程序 / APK 更新。当前内容包是完整 PCK，不是二进制差分补丁。

## 给维护者的构建入口

`tools/build_release.py` 默认构建三个离线平台包，输出到独立发行目录。确定服务后，使用 `--feed-url HTTPS清单地址` 内置真实地址。开发项目主场景不变，发布专用 bootstrap 只在隔离构建副本中启用。

`tools/publish_content_update.py --version 新版本 --build 递增构建号 --base-url HTTPS公开目录` 会在本地生成三平台 PCK 和签名 `manifest.json`，不会上传。只上传生成目录中的 `public` 内容，并最后更新清单；不要上传源码准备目录或密钥。`2026111603` / `2026111604` 是本次隔离验证的签名测试包，不是待发布的新游戏版本。

签名身份保存在相邻 `原始人大作战_发行准备/private_keys`：内容更新 RSA 私钥、Android keystore 及其密码均在此。应单独妥善备份并延续使用，不能发给玩家；更换 Android 密钥会影响已有安装的覆盖升级，丢失内容签名私钥会影响已发启动器接受后续更新。

安装前源码、原素材及当前存档快照见 `docs/native_ui_v32_baseline.json`。私有便携 JDK/SDK 位于本次发行准备目录，未安装到系统 Java 或改动全局 PATH。Godot 与字体许可已随包提供。
