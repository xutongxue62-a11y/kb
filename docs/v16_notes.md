# v0.16 — 特效、随从动作与密集战斗优化

在已认可的 v0.15 上继续。武器的距离、握持排布和碰撞命中保留；旧素材、旧预览及真实玩家进度保留，保护点见 `v16_baseline.json`。

特效改为有不同轮廓和材质的缓存手绘素材：木屑钝击、石斧楔斩、骨刃细切、弹弓石屑、烟火爆破、碎符镶晶、锥形贯刺、碎岩震地、骨箭穿裂、地面火舌、兽纹鼓波、多面碎晶、分叉电芒、幼龙牙爪。火场、鼓波和布置晶体采用对应表现，减少完整的大圆圈。重复拟声字最多六条并缩小，真实伤害数字不变。特效寿命、伤害判定和攻击节奏保持原有逻辑。

14 件武器在 3 级和 5 级沿用原有技能解锁，外形加强了各自的刃面、包边、绑带、骨饰、晶体和材料分区。战斗、HUD、商店和成长卡共用同一纹理工厂，无需重开存档。v15 的全部 1242 项武器距离/实际像素遮挡/发射朝向检查仍适用。

地面幼龙的普通追击由 460 降至 225 像素/秒，并加入加速、减速、接触停靠；步态根据实际位移推进，头、尾和双脚独立运动。停下或被地形挡住时不继续踏步。跟随速度适配玩家移速，落后时沿地面平滑归队，没有瞬移或飞越地形。飞行跟随物的翅膀独立扑动，身体小幅起伏，地面投影保持稳定；归队期间不从离屏位置发射超长光束。随从卡牌共用新的造型，旧 PNG 仍保留。

八种怪物增加按原身体遮罩裁切的鳞纹、甲片、伤痕和材质高光；新怪的原生 SVG 加入柔和明暗。首领背脊装饰贴合背部曲线。身体大小、角色镜像、敌人类型、精英识别、攻击预警及碰撞半径保留。

性能工作包括常用特效的有界缓存与预热、掉落物按两种资源分批实例绘制、石头碰撞候选的保守粗筛。全部掉落物仍为独立单位，渲染不合并、不回收、不自动计入奖励。出生或读档初始嵌石时仍使用旧版完整邻域恢复，避免优化漏掉被推出后触碰的第二块石头。没有降低怪物上限或攻击频率。

本机压力对比和完整测试数据见 `v16_verification.json`；使用相同初始场景与随机种子，42 个敌人、六件满级武器、两种最高级支援和至少 1500 个未收取资源，无视频录制并关闭垂直同步。帧时间包含系统调度，不能保证其他硬件或所有后期场景的帧率。

最终结果：42 组、7092 项回归通过，另有 14 项原生录制检查和 6 项原生实例读取检查通过。模拟耗时中位数 6.350→5.136ms；原生帧耗时中位数 26.666→20.158ms，p95 36.354→35.390ms。156 个旧素材及 67 个其他源码文件保持一致，4 个真实进度 JSON 已备份且未变化。v0.16 正常窗口已打开，启动日志正常，凭据见 `v16_opened.json`。

正式原生预览：`previews/v16_native_v4.mp4`。同目录保留 `effect_families.png`、`support_motion_phases.png`、`weapon_growth_sheet.png`、`monster_materials_before_after.png` 和真实战斗截图。所有测试/录制使用独立 SaveStore；最新玩家 JSON 另做逐文件备份，不覆盖旧进度。原生画面和技术验证不代替用户试玩验收，未宣称主观试听。
