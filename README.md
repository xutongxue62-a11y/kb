## 本版更新

- 小怪稀有血包、成长与掉落节奏调整，后期吸附加强。
- 改善攻击优先级、幼龙与主角辨识、受击反馈和飘字。
- 720p 界面、完整武器存档预览、角色翻页和音量设置修复。

## 操作

- 电脑：WASD／方向键移动，自动攻击；Shift 闪避，Esc 暂停，B 查看属性，空格切换阵型，Q 切换联动，E 切换目标优先，F5 保存。
- 安卓：左侧摇杆移动，右侧按钮闪避，其他功能点击游戏内按钮。
- 装备最多六把武器；宝箱可领取一份奖励，也可出售选中的奖励换金币。营地可购买、强化及更换武器。
